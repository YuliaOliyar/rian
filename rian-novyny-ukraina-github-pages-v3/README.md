# РІА Новини Україна — дизайн новостного сайта

Адаптивный пример для **rian.com.ua** по композиции архивного портала. В статическом демо **четыре URL**: главная, статья и две страницы рубрики «Політика». Отдельный ZIP содержит классическую тему WordPress **1.2.0**. Логотип `assets/images/logo.svg` — векторная отрисовка по предоставленному примеру, **не** исходный официальный файл. Демонстрационные заголовки и даты не являются актуальными новостями.

## Комплект

| Путь | Назначение |
| --- | --- |
| `index.html` | Главная и навигация по 11 утверждённым рубрикам |
| `politics.html` | Страница рубрики № 1: 10 материалов и номера страниц |
| `politics-2.html` | Страница рубрики № 2: ещё 4 материала и обратная ссылка |
| `article.html` | Статья, оценка 1–5 и комментарии **только для локального демо** |
| `assets/` | Локальные CSS, JS, иллюстрации, логотип и шрифт |
| `wordpress-theme/rian-novyny-ukraina/category.php` | Настоящий серверный архив любой рубрики, 10 записей на страницу |
| `wordpress-theme/rian-novyny-ukraina/comments.php` | Нативные комментарии WordPress |
| `wordpress-theme/rian-novyny-ukraina/inc/ratings.php` | AJAX-оценки записи с сохранением в WordPress |
| `rian-novyny-ukraina-github-pages-v3.zip` | Статическое демо для GitHub Pages; **распаковать** |
| `rian-novyny-ukraina-theme-v3.zip` | Тема WordPress; **не распаковывать** при установке |

## Замена демо на GitHub Pages

1. Распакуйте `rian-novyny-ukraina-github-pages-v3.zip`. В корне архива находятся `index.html`, `article.html`, `politics.html`, `politics-2.html`, папка `assets/`, `README.md` и скрытый `.nojekyll`; дополнительной обёртки-папки **нет**.
2. Откройте [репозиторий `yuliaoliyar/rian`](https://github.com/yuliaoliyar/rian), перейдите **в его корень** и выберите **Add file → Upload files**. Загрузите содержимое распакованного архива, **не ZIP**. Замените старые файлы и каталог `assets` целиком, иначе новый JS и CSS не появятся. Если существующий `README.md` не удаётся заменить вместе с остальными, пропустите его.
3. До сохранения убедитесь, что пути выглядят как `index.html`, `article.html`, `politics.html`, `politics-2.html`, `assets/js/participation.js` — **без** вложенной папки `rian-novyny-ukraina-github-pages/`. Нажмите **Commit changes**.
4. В **Settings → Pages** установите **Deploy from a branch → main → /(root)**. Проверьте главную `https://yuliaoliyar.github.io/rian/`, обе страницы рубрики `/politics.html` и `/politics-2.html`, а также `/article.html`.

Если вы специально хотите сохранить адрес `/rian/rian-novyny-ukraina-github-pages/`, файлы нужно обновлять **внутри** этой старой папки, но короткий адрес `/rian/` тогда не обновится. На GitHub Pages комментарии и ваша оценка сохраняются только в локальном хранилище вашего браузера: посетители не видят комментарии друг друга и общего рейтинга нет. Это честный интерактивный макет, а не новостной сервер. В статическом демо только рубрика «Політика» имеет отдельные страницы; остальные пункты меню ведут к тематическим блокам главной. После установки WordPress каждая из 11 рубрик получает собственный архив. Разные карточки демо открывают одну примерную статью.

## Установка и настройка WordPress

1. Сохраните резервную копию действующей темы. Через **Внешний вид → Темы → Добавить → Загрузить тему** установите `rian-novyny-ukraina-theme-v3.zip` и активируйте. При обновлении 1.0.0/1.1.0 подтвердите замену. Не загружайте в WordPress статический ZIP. Требуются WordPress 6.0+ и PHP 7.4+.
2. В **Записи → Рубрики** создайте или переименуйте рубрики из таблицы. Тема показывает **только эти 11 пунктов в двух полосах меню** и не удаляет другие ранее созданные рубрики из базы данных. До создания рубрики её пункт меню ведёт на главную; назначайте записям нужные рубрики и миниатюры. Название «Репортажs» из сообщения нормализовано до украинского «Репортажі».

| Рубрика | Рекомендуемый ярлык WordPress |
| --- | --- |
| Політика | `politics` |
| Економіка | `economy` |
| Суспільство | `society` |
| Надзвичайні події | `emergencies` |
| Культура | `culture` |
| Спорт | `sport` |
| Київ | `kyiv` |
| У світі | `world` |
| Інфографіка | `infographics` |
| Інтервʼю | `interviews` |
| Репортажі | `reports` |

3. В **Настройки → Чтение** выберите показ последних записей на главной; закреплённая запись становится главным материалом. Любая из 11 рубрик открывается через `category.php`: изображение, заголовок, дата, анонс, сайдбар и **по 10 материалов на страницу**, дальше — числовая пагинация. Адрес рубрики зависит от постоянных ссылок WordPress (часто `/category/politics/`). Меню формируется по списку выше автоматически; отдельная настройка меню не требуется.
4. В **Настройки → Обсуждение** разрешите комментарии и настройте модерацию; для старых записей проверьте, не закрыто ли обсуждение отдельно. WordPress хранит комментарии и применяет свои ограничения доступа, антиспам и настройки модерации. На статье есть форма, список ответов и пагинация комментариев, если она включена в настройках.
5. Любой посетитель может поставить **1–5 звёзд** записи. Оценки и среднее сохраняются в метаданных WordPress без внешнего плагина. Подписанный cookie на год ограничивает повторное голосование **из того же браузера**; дополнительно сервер ограничивает один голос на запись в сутки для одного сетевого IP (или учётной записи WordPress). IP сохраняется только в виде секретного хеша с 24-часовым сроком; люди за общим IP могут временно делить этот лимит. Смена IP и распределённая накрутка остаются возможными: для полноценного антифрода нужна отдельная система. AJAX-обработчик проверяет nonce, тип и статус записи, допустимое число звёзд.

Тема не импортирует новости и не включает WordPress, базу данных, видеоплеер или специализированную антиспам-систему. Привязка домена `rian.com.ua` требует отдельного доступа к DNS и хостингу.
