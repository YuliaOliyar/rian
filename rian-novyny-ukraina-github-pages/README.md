# РІА Новини Україна — дизайн новостного сайта

Адаптивный пример главной страницы и материала для **rian.com.ua** по композиции архивного портала. В проект входят статическое демо для GitHub Pages и отдельная классическая тема WordPress. Логотип `assets/images/logo.svg` — **векторная отрисовка по предоставленному визуальному примеру**, а не исходный официальный файл. Все тексты на демо-страницах — иллюстрации дизайна, не актуальные новости.

## Что находится в комплекте

| Путь | Назначение |
| --- | --- |
| `index.html` | Главная: шапка, рубрики, главный материал, лента, темы дня, публикации, медиа, события |
| `article.html` | Пример страницы новости: заголовок, метаданные, изображение, текст, теги, связанные материалы |
| `assets/` | Локальные CSS, JavaScript, фотографии, логотип и шрифт; внешних ресурсов для отображения нет |
| `wordpress-theme/rian-novyny-ukraina/` | Устанавливаемая тема WordPress с тем же оформлением и динамическими шаблонами |
| `rian-novyny-ukraina-github-pages.zip` | Отдельный архив только с файлами статического демо; его нужно **распаковать** перед загрузкой в GitHub |
| `rian-novyny-ukraina-theme.zip` | Архив темы для загрузки через интерфейс WordPress; его **не нужно** распаковывать при установке в WordPress |

## Как показать дизайн на GitHub Pages

1. Войдите на [GitHub](https://github.com/). В правом верхнем углу нажмите **+ → New repository**. Название, например, `rian-novyny-ukraina-demo`; видимость — **Public**; отметьте **Add a README file** и создайте репозиторий.
2. Распакуйте `rian-novyny-ukraina-github-pages.zip` **на своём компьютере**. В репозитории выберите **Add file → Upload files**. Перетащите **содержимое распакованной папки**, а не ZIP: `index.html`, `article.html`, каталог `assets` и, если виден, `.nojekyll`. Файлы должны оказаться в **корне** репозитория; `index.html` не должен лежать внутри дополнительной папки. Если GitHub сообщает, что `README.md` уже существует, пропустите локальный README или замените существующий отдельно.
3. Дождитесь появления файлов в списке и сохраните загрузку через **Commit changes** (в некоторых версиях интерфейса — **Propose changes** с последующим слиянием в `main`).
4. Откройте **Settings → Pages**. В **Build and deployment** выберите **Source: Deploy from a branch**, **Branch: main**, папку **/(root)** и нажмите **Save**. GitHub покажет адрес готового сайта после сборки; обычно он имеет вид `https://USERNAME.github.io/rian-novyny-ukraina-demo/`.
5. Откройте главную и нажмите на главный заголовок — должна открыться `article.html`. Логотип возвращает на главную. Поиск на статическом демо фильтрует примерные заголовки; он не ищет по базе WordPress.

Официальные инструкции: [загрузка файлов](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository) и [настройка источника GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site). GitHub Pages обслуживает **только статическое демо**, не исполняет PHP и не устанавливает WordPress. Привязка собственного домена `rian.com.ua` требует отдельного доступа к его DNS и настройки домена в GitHub Pages или WordPress-хостинге; этот комплект не меняет DNS.

## Как установить в WordPress

1. В панели WordPress откройте **Внешний вид → Темы → Добавить → Загрузить тему**. Выберите `rian-novyny-ukraina-theme.zip`, установите и активируйте. Требуются WordPress 6.0+ и PHP 7.4+.
2. В **Настройки → Чтение** выберите показ последних записей на главной. Добавьте записи с заголовками, текстом, краткими описаниями и **изображениями записи**; закреплённая запись становится главным материалом.
3. Создайте рубрики и назначьте их записям. Для автоматических запасных ссылок в меню подойдут ярлыки `politics`, `economy`, `society`, `events`, `culture`, `sport`, `kyiv`, `world`; для раздела прессцентра — `press`. Затем настройте настоящие меню в **Внешний вид → Меню**: места **Основное меню** и **Меню форматів**.
4. При желании замените логотип через **Внешний вид → Настроить → Идентичность сайта**; адреса Facebook/YouTube — в разделе **Соціальні мережі**. В **Внешний вид → Виджеты** доступна боковая колонка статьи. Поиск использует стандартные записи WordPress.
5. Главная страница, рубрики, поиск, обычные страницы, карточки записей и страница статьи заполняются из WordPress. Если записей нет, тема показывает подсказку вместо выдуманных новостей.

Тема не включает WordPress, базу данных, видеоплеер, редакционный импорт и реальные публикации. Изображения-заглушки можно заменить миниатюрами записей.
